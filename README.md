# CIFAR-10 Image Classification with CNN

A Convolutional Neural Network (CNN) built with TensorFlow/Keras to classify images from the CIFAR-10 dataset. The project covers exploratory data analysis, preprocessing, data augmentation, CNN architecture design, and model evaluation.

## Overview

CIFAR-10 consists of 60,000 color images (32x32 pixels) across 10 classes: airplane, automobile, bird, cat, deer, dog, frog, horse, ship, and truck. The dataset has 50,000 training images and 10,000 test images. The final model reaches approximately **87% accuracy** on the test set.

## Workflow

1. **Exploratory data analysis**
   - Inspected dataset shapes and class names.
   - Visualized sample images, class distribution, and pixel value distribution.
2. **Preprocessing**
   - Split the training set into train (90%) and validation (10%) sets.
   - Converted pixels to `float32` and normalized to the [0, 1] range.
   - One-hot encoded the labels.
3. **Data augmentation**
   - Random rotation (up to 15 degrees), width/height shifts (10%), horizontal flips, and zoom (10%) via `ImageDataGenerator`.
4. **Modeling and training**
   - Trained a CNN with the Adam optimizer and categorical cross-entropy loss for up to 50 epochs (batch size 64).
   - Used `EarlyStopping` and `ReduceLROnPlateau` callbacks on validation loss.
5. **Evaluation**
   - Plotted training vs. validation accuracy and loss curves.
   - Evaluated on the test set and analyzed errors with a confusion matrix and sample predictions.

## Model Architecture

| Stage | Layers |
|-------|--------|
| Block 1 | 2 x Conv2D(32, 3x3) + BatchNorm, MaxPooling, Dropout(0.25) |
| Block 2 | 2 x Conv2D(64, 3x3) + BatchNorm, MaxPooling, Dropout(0.30) |
| Block 3 | 2 x Conv2D(128, 3x3) + BatchNorm, MaxPooling, Dropout(0.35) |
| Classifier | Flatten, Dense(128) + BatchNorm, Dropout(0.40), Dense(10, softmax) |

All convolutional layers use ReLU activation and `same` padding.
